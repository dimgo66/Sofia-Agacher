# Дизайн-спецификация: Фавикон для персонального сайта Софии Агачер

## Обзор и контекст
Пользователь выбрал **Вариант B (Монограмма «СА»)** в качестве официального фавикона для персонального сайта писателя Софии Агачер. 
Данная концепция представляет собой изысканный золотой вензель «SA» на глубоком темно-синем фоне (#1c2331). Она подчеркивает личный бренд автора, статус (PhD, лауреат премий) и отлично сочетается с цветовой палитрой и премиальным стилем сайта.

## Предложенный дизайн и форматы

Мы создадим полный пакет фавиконов для поддержки всех типов устройств и браузеров (включая ретина-дисплеи и мобильные устройства):
1. **`favicon-16x16.png`** — стандартная иконка для вкладок браузера (низкое разрешение).
2. **`favicon-32x32.png`** — стандартная иконка для вкладок браузера (высокое разрешение / Retina).
3. **`apple-touch-icon.png` (180x180)** — иконка для закладок на домашних экранах iOS-устройств (Apple-девайсы).
4. **`favicon.png` (512x512)** — исходное высокое разрешение для современных Android-устройств и PWA.

## Схема внедрения в HTML

В раздел `<head>` файла `index.html` будут добавлены следующие метатеги для подключения фавиконов:

```html
<!-- Иконки для вкладок и современных браузеров -->
<link rel="icon" type="image/png" sizes="32x32" href="favicon-32x32.png">
<link rel="icon" type="image/png" sizes="16x16" href="favicon-16x16.png">

<!-- Иконка для устройств Apple (iOS) -->
<link rel="apple-touch-icon" sizes="180x180" href="apple-touch-icon.png">

<!-- Иконка общего назначения -->
<link rel="icon" type="image/png" sizes="512x512" href="favicon.png">
```

## Технический процесс создания (PowerShell + .NET)
Так как на системе пользователя доступен PowerShell с поддержкой .NET сборки `System.Drawing`, мы применим автоматический скрипт для высококачественного изменения размеров исходного изображения `elegant_monogram_icon.png` (512x512) и сохранения результатов непосредственно в корневую директорию проекта.

## План верификации

### Автоматическая проверка
- Проверить наличие всех созданных файлов в корневой папке проекта.
- Проверить валидность HTML-структуры `index.html` после добавления метатегом.

### Ручная проверка
- Запустить локальный сервер и убедиться, что иконка отображается во вкладке браузера.
- Использовать инструменты разработчика Chrome DevTools для проверки загрузки ресурсов без ошибок 404.
